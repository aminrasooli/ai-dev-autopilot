# Provisional results

Real measurements taken **before** the corpus's ground truth was
human-approved. They are evidence, not results: quotable as "what a
model did against corpus `<fingerprint>` on this date", never as a
benchmark score, and never on a leaderboard.

They are kept because deleting inconvenient measurements is the failure
mode the experiment registry exists to prevent. If ground truth changes
in review, these stay — attached to the corpus fingerprint they actually
ran against.

See `eval/EXPERIMENTS.md` for the registry, and
`CROSS-MODEL-ADJUDICATION.md` (operational, uncommitted) for what this
evidence showed.
