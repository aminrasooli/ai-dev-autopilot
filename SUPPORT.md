# Support

AI Dev Autopilot is a volunteer-maintained, early-stage project. There is no
SLA; support is best effort.

## Where to ask

- **Questions, usage help, "is this expected?"** — open a
  [GitHub issue](https://github.com/aminrasooli/ai-dev-autopilot/issues/new/choose).
  Check [docs/FAQ.md](docs/FAQ.md) first; it answers the questions that come up
  most.
- **A bug — something documented that doesn't hold on your machine.** Open an
  issue using the **Bug report** template. Reproducible reports get looked at
  first; the template asks for exactly what makes a report reproducible (OS,
  Claude Code version, which `make` targets you ran, `make doctor` output, the
  exact command).
- **A boundary you got past that the README says is human-only** — a credential
  read, `sudo`, destructive command, or anything in the
  [Hard human boundaries](README.md#hard-human-boundaries) table that didn't
  stop for a human. Report this privately, not as a public issue.

## Reporting a security issue

Please report vulnerabilities privately through **GitHub Private Vulnerability
Reporting** — the **Report a vulnerability** button on the repository's
Security tab. If that button is not visible, open an issue that says only that
you have a security report and are waiting for a private channel, with no
details, and wait for a maintainer to enable private reporting and follow up.
Full scope and what to include: [SECURITY.md](SECURITY.md).

## Maintainer

One maintainer, best effort, no SLA. If you'd like credit for a report or fix
in release notes, say so and how you'd like to be named.
